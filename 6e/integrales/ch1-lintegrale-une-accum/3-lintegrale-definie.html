L’intégrale définie

Définition 1.2 — intégrale définie

Soit \(f\) une fonction définie sur \([a ; b]\), avec \(a < b\). Pour un naturel \(n \geq 1\), on découpe \([a ; b]\) en \(n\) morceaux de même longueur \(\Delta x = \frac{b - a}{n}\) :

\[ x_{0} = a, \quad x_{1} = a + \Delta x, \quad \ldots, \quad x_{i} = a + i \Delta x, \quad \ldots, \quad x_{n} = b. \]

Dans chaque morceau \([x_{i-1} ; x_{i}]\), on choisit un nombre \(d_{i}\), et on note

\[ S_{n} = f(d_{1})(x_{1} - x_{0}) + f(d_{2})(x_{2} - x_{1}) + \ldots + f(d_{n})(x_{n} - x_{n-1}). \]

Pour \(n = 4\) : chaque produit \(f(d_{i})(x_{i} - x_{i-1})\) est l’aire signée d’un rectangle.

Si la suite \((S_{n})\) a une limite, cette limite est l’intégrale de \(f\) de \(a\) à \(b\), notée

\[ \int_{a}^{b} f(x) \,\mathrm{d} x = \lim\limits_{n \to +\infty} S_{n}. \]

Propriété 1.2 — encadrement

Avec les notations de la définition 1.2, on note \(D_{n}\) la somme par défaut (plus petite valeur de \(f\) sur chaque morceau) et \(E_{n}\) la somme par excès (plus grande valeur de \(f\) sur chaque morceau). Quels que soient les nombres \(d_{i}\) choisis,

\[ D_{n} \leq S_{n} \leq E_{n}. \]

Si \(\lim\limits_{n \to +\infty} (E_{n} - D_{n}) = 0\), les suites \((D_{n})\), \((S_{n})\) et \((E_{n})\) ont la même limite : \(\int_{a}^{b} f(x) \,\mathrm{d} x\) ne dépend pas du choix des \(d_{i}\).

Remarque 1.2

Les fonctions de ce cours ont une intégrale sur tout intervalle \([a ; b]\) inclus dans leur domaine, et cette intégrale ne dépend pas du choix des \(d_{i}\). À l’activité 1.2, \(E_{n} - D_{n} = \frac{8}{n}\) a pour limite 0.

Lire la notation. Le signe \(\int\) est un S allongé : il rappelle une somme. \(f(x) \,\mathrm{d} x\) rappelle les produits \(f(d_{i})(x_{i} - x_{i-1})\) : \(\,\mathrm{d} x\) désigne la longueur d’un morceau. \(a\) est la borne inférieure, \(b\) la borne supérieure. La lettre \(x\) peut être remplacée par une autre : \(\int_{0}^{2} (x^{2} - 1) \,\mathrm{d} x = \int_{0}^{2} (t^{2} - 1) \,\mathrm{d} t\).

Propriété 1.3 — intégrale et aire signée

Pour \(a < b\), \(\int_{a}^{b} f(x) \,\mathrm{d} x\) est l’aire signée entre le graphique de \(f\) et l’axe des abscisses sur \([a ; b]\) : l’aire au-dessus de l’axe moins l’aire en dessous. Si \(f\) est le débit d’une grandeur, \(\int_{a}^{b} f(t) \,\mathrm{d} t\) est la variation de cette grandeur entre les instants \(a\) et \(b\).

\[ \int_{a}^{b} f(x) \,\mathrm{d} x = A_{1} - A_{2} + A_{3}. \]

Définition 1.3 — bornes égales ou inversées

Pour \(a < b\) :

\[ \int_{a}^{a} f(x) \,\mathrm{d} x = 0 \quad \text{et} \quad \int_{b}^{a} f(x) \,\mathrm{d} x = - \int_{a}^{b} f(x) \,\mathrm{d} x. \]

En parcourant \([a ; b]\) de \(b\) vers \(a\), les longueurs \(x_{i} - x_{i-1}\) sont négatives : chaque produit change de signe.

Exemple 1.1 — calculer une intégrale avec des aires

Calculer \(\int_{-2}^{3} x \,\mathrm{d} x\).

Sur \([-2 ; 0]\), la partie située sous l’axe est un triangle d’aire \(\frac{2 \cdot 2}{2} = 2\). Sur \([0 ; 3]\), la partie située au-dessus de l’axe est un triangle d’aire \(\frac{3 \cdot 3}{2} = 4{,}5\).

\[ \int_{-2}^{3} x \,\mathrm{d} x = 4{,}5 - 2 = 2{,}5. \]

Calcule à l’aide d’aires de rectangles, de triangles ou de disques.

  1. \(\int_{-3}^{3} 2 \,\mathrm{d} x\)

  2. \(\int_{0}^{3} (-2) \,\mathrm{d} x\)

  3. \(\int_{0}^{4} (x - 1) \,\mathrm{d} x\)

  4. \(\int_{1}^{-2} 3 \,\mathrm{d} x\)

  5. \(\int_{-1}^{1} x^{3} \,\mathrm{d} x\)

  6. \(\int_{-2}^{2} \sqrt{4 - x^{2}} \,\mathrm{d} x\)

Rectangle \(6 \cdot 2 = 12\). b) Rectangle sous l’axe : \(-(3 \cdot 2) = -6\). c) Sous l’axe sur \([0 ; 1]\) : \(0{,}5\) ; au-dessus sur \([1 ; 4]\) : \(\frac{3 \cdot 3}{2} = 4{,}5\) ; intégrale : \(4{,}5 - 0{,}5 = 4\). d) \(\int_{1}^{-2} 3 \,\mathrm{d} x = - \int_{-2}^{1} 3 \,\mathrm{d} x = -(3 \cdot 3) = -9\). e) Le graphique de \(x^{3}\) est symétrique par rapport à l’origine : la partie sous l’axe sur \([-1 ; 0]\) a la même aire que la partie au-dessus sur \([0 ; 1]\) ; intégrale : 0. f) Le graphique est le demi-cercle de centre \((0 ; 0)\) et de rayon 2, au-dessus de l’axe : \(\frac{\pi \cdot 2^{2}}{2} = 2 \pi\).

Je veux plus de détails

  1. Rectangle au-dessus de l’axe : \(6 \cdot 2 = 12\).

  2. Rectangle sous l’axe : \(\int_{0}^{3} (-2) \,\mathrm{d} x = -(3 \cdot 2) = -6\).

  3. Sous l’axe sur \([0 ; 1]\) : triangle d’aire \(0{,}5\). Au-dessus sur \([1 ; 4]\) : triangle d’aire \(\frac{3 \cdot 3}{2} = 4{,}5\). \(\int_{0}^{4} (x - 1) \,\mathrm{d} x = 4{,}5 - 0{,}5 = 4\).

  4. Bornes inversées : \(\int_{1}^{-2} 3 \,\mathrm{d} x = - \int_{-2}^{1} 3 \,\mathrm{d} x = -(3 \cdot 3) = -9\).

  5. Le graphique de \(x^{3}\) est symétrique par rapport à l’origine : la partie sous l’axe sur \([-1 ; 0]\) a la même aire que la partie au-dessus sur \([0 ; 1]\). \(\int_{-1}^{1} x^{3} \,\mathrm{d} x = 0\).

  6. \(y = \sqrt{4 - x^{2}}\) donne \(x^{2} + y^{2} = 4\) avec \(y \geq 0\) : le graphique est le demi-cercle de centre \((0 ; 0)\) et de rayon 2, au-dessus de l’axe. \(\int_{-2}^{2} \sqrt{4 - x^{2}} \,\mathrm{d} x = \frac{\pi \cdot 2^{2}}{2} = 2 \pi\).

  • Donner 6 en b) : la partie sous l’axe compte négativement.
  • Oublier le signe moins en d) quand la borne inférieure est plus grande que la borne supérieure.

✎ Exercice 1.9 C3 ★★☆

Le graphique est celui de \(f(x) = |x| - 1\).

  1. Calcule \(\int_{-1}^{1} f(x) \,\mathrm{d} x\), \(\int_{1}^{3} f(x) \,\mathrm{d} x\) et \(\int_{-3}^{3} f(x) \,\mathrm{d} x\).

  2. Calcule l’aire totale des parties comprises entre le graphique et l’axe des abscisses sur \([-3 ; 3]\). Pourquoi est-elle différente de \(\int_{-3}^{3} f(x) \,\mathrm{d} x\) ?

  1. Sur \([-1 ; 1]\) : triangle sous l’axe d’aire \(\frac{2 \cdot 1}{2} = 1\), donc \(\int_{-1}^{1} f(x) \,\mathrm{d} x = -1\). Sur \([1 ; 3]\) : triangle au-dessus d’aire \(\frac{2 \cdot 2}{2} = 2\). Par symétrie, \(\int_{-3}^{-1} f(x) \,\mathrm{d} x = 2\) ; \(\int_{-3}^{3} f(x) \,\mathrm{d} x = 2 - 1 + 2 = 3\). b) \(2 + 1 + 2 = 5\). L’intégrale compte négativement la partie sous l’axe : \(5 - 2 \cdot 1 = 3\).

Où le graphique coupe-t-il l’axe des abscisses ?

Le graphique coupe l’axe en \(-1\) et en 1 : découpe \([-3 ; 3]\) en trois triangles.

Je veux plus de détails

  1. Sur \([-1 ; 1]\), le graphique est sous l’axe et forme un triangle d’aire \(\frac{2 \cdot 1}{2} = 1\) : \(\int_{-1}^{1} f(x) \,\mathrm{d} x = -1\). Sur \([1 ; 3]\), il est au-dessus et forme un triangle d’aire \(\frac{2 \cdot 2}{2} = 2\) : \(\int_{1}^{3} f(x) \,\mathrm{d} x = 2\). Par symétrie, \(\int_{-3}^{-1} f(x) \,\mathrm{d} x = 2\). Relation de Chasles : \(\int_{-3}^{3} f(x) \,\mathrm{d} x = 2 - 1 + 2 = 3\).

  2. Aire totale : \(2 + 1 + 2 = 5\). L’intégrale compte négativement la partie sous l’axe, d’où \(5 - 2 \cdot 1 = 3\).

  • Répondre 5 pour l’intégrale : c’est l’aire totale, sans signe.

✎ Exercice 1.10 ⟵ à faire à la maison C3 ★★☆
