Aire d’une surface plane

Activité 4.1 — intégrale et aire

Soit \(f(x) = x^{2} - 4\) sur \([-3 ; 3]\).

  1. Calcule \(\int_{-3}^{3} f(x) \,\mathrm{d} x\).

\([\frac{x^{3}}{3} - 4x]_{-3}^{3} = (9 - 12) - (-9 + 12) = -6\).

  1. Ce nombre est-il l’aire de la surface comprise entre le graphique et l’axe des abscisses ? Pourquoi ?

Non : une aire est positive. Sur \([-2 ; 2]\), le graphique est sous l’axe et cette partie est comptée négativement.

  1. Calcule les zéros de \(f\) dans \(]-3 ; 3[\), puis l’intégrale de \(f\) entre deux bornes consécutives parmi \(-3\), les zéros et 3. Additionne les valeurs absolues de ces intégrales.

Zéros : \(x^{2} - 4 = 0\) donne \(x = -2\) et \(x = 2\). Avec \(F(x) = \frac{x^{3}}{3} - 4x\) : \(F(-3) = 3\), \(F(-2) = \frac{16}{3}\), \(F(2) = -\frac{16}{3}\), \(F(3) = -3\). \(\int_{-3}^{-2} f(x) \,\mathrm{d} x = \frac{7}{3}\) ; \(\int_{-2}^{2} f(x) \,\mathrm{d} x = -\frac{32}{3}\) ; \(\int_{2}^{3} f(x) \,\mathrm{d} x = \frac{7}{3}\). Aire : \(|\frac{7}{3}| + |-\frac{32}{3}| + |\frac{7}{3}| = \frac{46}{3} \approx 15{,}33\) u.a.

  1. Pourquoi les valeurs absolues donnent-elles l’aire ?

Entre deux zéros consécutifs, \(f\) garde le même signe : l’intégrale y vaut l’aire de la partie, ou son opposé. La valeur absolue donne l’aire dans les deux cas.

Propriété 4.1 — aire entre un graphique et l’axe des abscisses

Soit \(a < b\) et \(r_{1} < r_{2} < \ldots < r_{k}\) les zéros de \(f\) dans \(]a ; b[\). L’aire de la surface comprise entre le graphique de \(f\), l’axe des abscisses et les droites \(x = a\) et \(x = b\) vaut

\[ \left\vert \int_{a}^{r_{1}} f(x) \,\mathrm{d} x\right\vert{} + \left\vert \int_{r_{1}}^{r_{2}} f(x) \,\mathrm{d} x\right\vert{} + \ldots + \left\vert \int_{r_{k}}^{b} f(x) \,\mathrm{d} x\right\vert{}. \]

Si \(f\) n’a pas de zéro dans \(]a ; b[\), l’aire vaut \(\left\vert \int_{a}^{b} f(x) \,\mathrm{d} x\right\vert{}\).

Procédure pour calculer une aire.

  1. Représenter la fonction sur \([a ; b]\) et repérer la surface.
  2. Calculer les zéros de \(f\) dans \(]a ; b[\).
  3. Calculer l’intégrale de \(f\) entre deux bornes consécutives (de \(a\) au premier zéro, entre deux zéros, du dernier zéro à \(b\)).
  4. Additionner les valeurs absolues de ces intégrales ; donner le résultat en unités d’aire.

Les valeurs absolues dispensent d’étudier le signe de \(f\).

Remarque 4.1

L’unité d’aire (u.a.) est l’aire du rectangle de côtés 1 et 1 dans le repère. Si une unité vaut 2 cm sur l’axe des abscisses et 1 cm sur l’axe des ordonnées, 1 u.a. \(= 2 \text{cm}^{2}\).

✎ Exercice 4.1 A4 ★☆☆

Calcule l’aire de la surface comprise entre le graphique de \(\sin\) et l’axe des abscisses sur \([0 ; 2 \pi]\). Compare avec \(\int_{0}^{2 \pi} \sin x \,\mathrm{d} x\).

Zéro de \(\sin\) dans \(]0 ; 2\pi[\) : \(\pi\). \(\int_{0}^{\pi} \sin x \,\mathrm{d} x = [-\cos x]_{0}^{\pi} = 2\) ; \(\int_{\pi}^{2\pi} \sin x \,\mathrm{d} x = [-\cos x]_{\pi}^{2\pi} = -1 - 1 = -2\). Aire : \(|2| + |-2| = 4\) u.a. ; l’intégrale vaut \(2 - 2 = 0\).

Relis la propriété 4.1 et la procédure qui la suit.

Quels sont les zéros de \(\sin\) dans \(]0 ; 2\pi[\) ?

Le seul zéro est \(\pi\) : calcule \(\int_{0}^{\pi} \sin x \,\mathrm{d} x\) et \(\int_{\pi}^{2\pi} \sin x \,\mathrm{d} x\).

Aire : 4 u.a. ; intégrale : 0.

Je veux plus de détails

Zéro de \(\sin\) dans \(]0 ; 2\pi[\) : \(\pi\). \(\int_{0}^{\pi} \sin x \,\mathrm{d} x = [-\cos x]_{0}^{\pi} = 1 + 1 = 2\) ; \(\int_{\pi}^{2\pi} \sin x \,\mathrm{d} x = [-\cos x]_{\pi}^{2\pi} = -1 - 1 = -2\). Aire : \(|2| + |-2| = 4\) u.a. ; \(\int_{0}^{2\pi} \sin x \,\mathrm{d} x = 2 - 2 = 0\).

  • Donner 0 comme aire : une aire est positive.
  • Oublier de découper en \(\pi\).

✎ Exercice 4.2 A4 ★★☆

Soit \(f(x) = x^{3} - x\). Représente \(f\) sur \([-1 ; 1]\), puis calcule l’aire de la surface comprise entre son graphique et l’axe des abscisses sur cet intervalle. Dans le repère, une unité vaut 3 cm sur chaque axe : donne l’aire en \(\text{cm}^{2}\).

\(f(x) = x(x - 1)(x + 1)\) : zéro dans \(]-1 ; 1[\) : 0. Primitive : \(F(x) = \frac{x^{4}}{4} - \frac{x^{2}}{2}\). \(\int_{-1}^{0} f(x) \,\mathrm{d} x = 0 - (\frac{1}{4} - \frac{1}{2}) = \frac{1}{4}\) ; \(\int_{0}^{1} f(x) \,\mathrm{d} x = (\frac{1}{4} - \frac{1}{2}) - 0 = -\frac{1}{4}\). Aire : \(|\frac{1}{4}| + |-\frac{1}{4}| = \frac{1}{2}\) u.a. ; 1 u.a. \(= 9 \text{cm}^{2}\), donc l’aire vaut \(4{,}5 \text{cm}^{2}\).

Relis la propriété 4.1 et la remarque 4.1.

Quels sont les zéros de \(x^{3} - x\) dans \(]-1 ; 1[\) ?

\(x^{3} - x = x(x - 1)(x + 1)\) ; une primitive est \(\frac{x^{4}}{4} - \frac{x^{2}}{2}\).

\(\frac{1}{2}\) u.a., soit \(4{,}5 \text{cm}^{2}\).

Je veux plus de détails

\(f(x) = x(x - 1)(x + 1)\) : le seul zéro dans \(]-1 ; 1[\) est 0. Une primitive est \(F(x) = \frac{x^{4}}{4} - \frac{x^{2}}{2}\). \(\int_{-1}^{0} f(x) \,\mathrm{d} x = 0 - (\frac{1}{4} - \frac{1}{2}) = \frac{1}{4}\) ; \(\int_{0}^{1} f(x) \,\mathrm{d} x = -\frac{1}{4}\). Aire : \(|\frac{1}{4}| + |-\frac{1}{4}| = \frac{1}{2}\) u.a. Une unité vaut 3 cm sur chaque axe : 1 u.a. \(= 9 \text{cm}^{2}\), donc l’aire vaut \(4{,}5 \text{cm}^{2}\).

  • Calculer \(\int_{-1}^{1} f(x) \,\mathrm{d} x = 0\) sans découper en 0.
  • Prendre 1 u.a. \(= 3 \text{cm}^{2}\) : l’unité d’aire est un carré de côté 3 cm.
