Jalons et règles

dates importantes saisies à la main

Les jalons (conseil de classe, remise de notes…) se saisissent dans le fichier unif/jalons.json du dépôt privé : { "jalons": [ { "date": "2026-11-06", "texte": "Conseil de classe 5TTy", "ecole": "urs" } ] } (« ecole » : « urs » ou « unif »). Les événements « importants » se règlent dans config.json du site (mots-clés, catégories).
